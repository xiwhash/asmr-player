逆向说明

基于 www.asmr.one 线上包（Quasar/Vue + Vuex，含 20 个异步 chunk）静态分析复刻，聚焦播放器与压缩包导入两条链路。

媒体流{apiHost}/api/media/stream/{hash}?token={jwt}
媒体下载{apiHost}/api/media/download/{hash}?token={jwt}
封面{apiHost}/api/cover/{workId}.jpg?type=main|sam|240x240
接口GET /api/work/{id}、GET /api/tracks/{id}?v=2
API 多源api.asmr-200.com（latest）/ api.asmr.one（original）/ api.asmr-100.com / api.asmr-300.com
播放状态机命令信号 wantPlay / wantPause / wantSeek，消费后重置
字幕模式subtitleDisplayMode: in-app | pip
画中画隐藏 canvas（2×视口宽，20:3）→ captureStream(0) → video → PiP；每次歌词变化 requestFrame() 推帧；优先 Document PiP（480×120），回退 Video PiP
字幕表subtitle_package / subtitle_content / subtitle_record
本页为本地模式：压缩包内的音频与字幕全部留在浏览器内，blob URL 播放，数据存 IndexedDB。 画中画在非 HTTPS 的局域网地址下会自动走 Video PiP 通道（Document PiP 需安全上下文）。
